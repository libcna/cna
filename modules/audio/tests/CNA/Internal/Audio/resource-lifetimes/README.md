# HND-XACT-04 native notification/resource lifetimes

All74 genuine Microsoft XACT3.6 x86/x64 cells pass, including retained/ordinary
resident positive controls and the repeated resident/normal shape. PROVENANCE
pins matrix, probe/EXE/DLL/driver and existing original CC0 fixture identities.
The v5 per-cell ordinal fixes a naming collision without dropping a measurement.

Never-played noninteractive cues prepare/destroy wave objects without WAVEPLAY;
interactive cues resolve no waves. Stop settles32, Destroy removes the handle.
Destroy-playing stops actual current waves and destroys prepared successors, but
resolved bank ownership survives until sound-bank destruction. EOF can release
interactive waves while the cue remains Playing8/count1. Clones hold independent
owners; weighted clone choices may match or differ. Ordered native4/CNA3 remains
open: complete native lifecycles are checked here, not claimed as CNA parity.

Unregister cells show no callbacks after the final unregister returns in these
runs, while playback state and resources continue to settle as in controls.
This is a native registration observation, not a managed CNA notification API
or proof of concurrent callback quiescence. Native-Windows/managed execution,
forced INUSE bank destruction, threading races and exact timing remain unqualified.

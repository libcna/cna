## Purpose
Renders every checked-in `tools/xna-oracle/scenes/*.scene` through the real D3D9 renderer
(`cna_oracle_render.exe`, via Wine+DXVK) and diffs each result against the checked-in real XNA 4.0
reference PNG at exact-match tolerance (0).

## Executive Verdict
Correct, and notably strict about test integrity: the top-of-file comment explicitly states
reference PNGs must be regenerated by hand against the real XNA oracle if a scene's expected output
ever needs to change, and explicitly warns "never widen this script's own tolerance to turn a red
comparison green" — a direct, self-imposed guard against the common anti-pattern of loosening a
test's pass criteria to make a failure disappear.

## Checklist Results
- Correctly deliberately does NOT need the separate XNA Wine prefix (only the D3D9 DXVK prefix),
  with an explicit rationale (reference PNGs are pre-captured and checked in, not re-rendered live
  against a real XNA runtime each time).
- Missing-reference-image and renderer-failure cases are both distinct, clearly-labeled `FAIL`
  branches (not silently skipped or merged into a generic failure).
- `trap 'rm -rf "$WORK_DIR"' EXIT` correctly cleans up the temp render directory regardless of exit
  path.

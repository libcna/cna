# PackedVector Golden Values

Reference table derived from FNA source bit-packing formulas
(`/rv/data/library/github.com/FNA-XNA/FNA/src/Graphics/PackedVector/`).

All values computed via Python using the same arithmetic as the FNA C# source:
rounding via `+0.5` then truncation, channel clamping, IEEE 754 half-float
via `struct.pack('<e')`.

---

## Alpha8

Constructor takes `float alpha`, packs as `byte = (byte)clamp(alpha,0,1)*255`.
ToVector4 → (0, 0, 0, packed/255).

| alpha | packed (hex) | packed (dec) | ToVector4.W |
|-------|-------------|-------------|-------------|
| 0.00 | 0x00 | 0 | 0.00000000 |
| 0.25 | 0x40 | 64 | 0.25098039 |
| 0.50 | 0x80 | 128 | 0.50196078 |

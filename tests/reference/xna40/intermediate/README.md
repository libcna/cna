# XNA 4.0 IntermediateSerializer corpus

Generated by `tools/xna-pipeline-oracle/intermediate/run-intermediate-oracle.sh`, which runs the
genuine Microsoft XNA Game Studio 4.0 `IntermediateSerializer` (under the .NET Framework 4.0 in
Wine) over the CNA-authored types in `IntermediateOracle.cs`. Every file is output of that run;
nothing here was written by hand except the `*.input.xml` variants, which are the XML the driver
handed to the deserializer.

* `<case>.xml` — what the serializer wrote for the graph named `<case>`.
* `<case>.roundtrip.xml` — present only when re-serializing the deserialized object differed.
* `<case>.error.txt` — present when the serializer refused the graph.
* `<case>.input.xml` / `<case>.normalized.xml` — an acceptance case: the XML offered, and the
  accepted object serialized back.
* `manifest.json` — every case with its status (`written`, `round-trip-differs`, `failed`,
  `accepted`, `rejected`) and the exception message for the refused ones.

The readable form of what this corpus shows is `docs/xna-intermediate-xml-format.md`; CNA's
`IntermediateSerializer` tests read these files directly. Regenerate rather than edit.

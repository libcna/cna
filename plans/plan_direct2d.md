# Direct2D backend — plán 2D parity s EasyGL

> **Rozhodnutý rozsah:** `DIRECT2D` je trvale **2D-only** backend. Nepřidává se do něj 3D
> pipeline jen proto, že Direct2D interně používá D3D11 device pro GPU akceleraci a prezentaci.
> Pro 3D slouží existující `D3D11` backend.
>
> **Stav:** `⬜` znamená neimplementováno, `🟨` znamená implementováno nebo rozpracováno bez
> dokončeného nativního Windows pixelového ověření a `🔬` technický spike před implementací.
> Wine/Proton-DXVK jsou hodnotné regresní běhy, ale nenahrazují Windows Direct2D pro built-in
> effects, image composite modes, fyzický swap-chain výstup a DPI. Každá hotová položka musí mít
> veřejný pixelový test; položky závislé na těchto funkcích musí navíc projít nativním Windows
> Direct2D.

## Co EasyGL umí navíc a co je zde v rozsahu

Současný Direct2D backend již implementuje `Texture2D`, `RenderTarget2D`, `SpriteBatch`, běžné
presentation módy, standardní blend presety, scissor rectangle a staging readback **swap chain
backbufferu**. EasyGL je širší GLES3 backend; tento plán vybírá pouze rozdíly, které mají smysl
pro poctivý 2D Direct2D backend.

| Funkce EasyGL | Direct2D nyní | Rozhodnutí pro Direct2D |
|---|---|---|
| `RenderTarget2D::GetData` a readback aktivního cíle | level 0 čte aktivní nebo jmenovaný 2D target | **Implementováno:** skutečný 2D readback |
| Tint, flip, Wrap/Mirror pro render target jako SpriteBatch zdroj | GPU ImageBrush/effect cesta; chybějící runtime effect se pojmenovaně odmítne | **V rozsahu:** bez CPU shadow a bez D3D compositingu |
| Mipové levely `Texture2D` a `RenderTarget2D` | Texture2D má authored levely; mipmapped RT je odmítnut | **Rozhodnuto:** chybný NPOT RT generator odstraněn |
| Point/linear/anisotropic + adresování 2D sprite zdrojů | devět filtrů a Clamp/Wrap/Mirror na podporovaných zdrojích | **Implementováno:** čisté `ID2D1DeviceContext` vzorkování |
| Scissor enable a viewport | oba stavy mají 2D transform+clip kontrakt | **Implementováno** |
| Context loss/recovery | textura se obnoví ze shadow, RT transparentně, stale generation se odmítne | **Implementováno pro 2D** |
| MSAA | 0 | **Vyřešeno:** trvalé `0`/`false`; Direct2D primitive antialiasing není `MultiSampleCount` a D3D multisample/resolve pipeline je mimo rozsah |
| Obecné blend faktory, blend equation, write/sample mask | přesné 2D subsety; Additive false/rejected | **Rozhodnuto:** přesný Porter–Duff subset, zbytek pojmenovaně odmítnut |
| 3D buffery/draw, depth/stencil, MRT, cube/volume textury, queries, custom shader effects | nepodporováno | **Mimo rozsah:** patří do `D3D11` backendu |

## Pevné hranice

Následující EasyGL schopnosti nejsou úkoly pro Direct2D a zůstávají explicitně nepodporované:

- vertex/index buffery (16- i 32-bit), `Draw*`, `Draw*Ex` a instancing;
- `BasicEffect` a ostatní stock 3D efekty, custom `Effect`/GLSL shader pipeline;
- depth/stencil resources a state, 3D clear operace, culling, wireframe a depth bias;
- `Texture3D`, `TextureCube`, `RenderTargetCube`, environment mapping a skinning;
- MRT, occlusion queries a obecné D3D11 sampler state; Direct2D anisotropie pro SpriteBatch je
  naproti tomu čistě 2D schopnost a patří do D2D-32;
- `BlendState` kombinace bez přesného Direct2D Porter–Duff ekvivalentu, constant blend factor,
  color-write a multisample mask.

`SupportsCapability()` musí pro tyto funkce zůstat `false`, 3D vstupy musí dál selhávat
pojmenovanou výjimkou a dokumentace má uživatele odkázat na `CNA_GRAPHICS_BACKEND=D3D11`.

## Fáze D2D-3 — přesnost a omezení compositingu

Direct2D primitive blend umí `SourceOver`, `Copy` a `Add`; image composite API navíc poskytuje
přesné Porter–Duff režimy. To stále nepokrývá plný XNA/D3D blend model. Tento backend nebude
obcházet zbytek vlastním D3D11 compositing pasem, protože by se tím stal druhým D3D11 backendem.

## Audit 2026-08-03 — disposition při adaptaci

Historické potvrzené chyby jsou zachovány jako provenance, ale už nejsou aktuální tvrzení:

- NativeBackBuffer/logical readback, premultiplied tint, depth/raster rejection, stale-RT bind a
  resize/presentation transakčnost jsou opravené a mají regression oracles.
- XNA Additive není aproximován přes `PLUS`; capability je false a všechny varianty se odmítají.
- Authored Texture2D MipLinear je skutečně interpolovaný. Mipmapped RT je po D2D-78 odmítnutý a
  generator odstraněný. CPU shadow zůstává záměrně autoritou pro authored mipy a fallback draw.
- Positive ImageBrush crop, Linear edge behavior a D2D-82 transform mají nezávislé oracles.
- Fyzický DPI/presentation, native effects/composites a dispose/update soak rozšíření zůstávají
  výslovně klasifikované níže jako external nebo process/coverage, nikoli skrytý production defect.

## Pořadí a pravidla ověření

1. Neměň deliberate 2D-only hranici bez nové explicitní autorizace: žádná 3D/D3D11 fallback cesta,
   Additive aproximace ani obnovení flawed RT mip generatoru.
2. `D2D-22` zůstává nativní gate pro built-in effects/composites a `D2D-126` fyzická
   presentation/DPI gate. Xvfb Wine není důkazem ani jedné.
3. Stav `✅` vyžaduje podporovaný kontrakt s unit/public oracle nebo explicitní tested rejection;
   compatibility skip nesmí být prezentován jako native pass.
4. Direct2D build/test commands must keep an explicit numeric maximum of two jobs. Unit, smoke,
   parity and lifetime run sequentially through the dedicated Direct2D runner.
5. Performance, soak, mutation, differential and refactor work remains nonblocking unless it
   uncovers a concrete supported-path production defect; such a defect immediately reopens the gate.

# Module-examples campaign — inventory, move map, and no-loss reconciliation

Campaign: move every tracked CNA example into its owning physical module
(`feature/module-examples`, based on the accepted naming-normalization head
`16f76cf1a01cddf07ab03b28d83f36e6bca7d8c0`, tree `51471e0144ac9859235a0c17b7722037fd041d2d`).

## Evidence in this directory

- `baseline/` — pre-move inventory at the naming head: `example-files.tsv` (1373 tracked
  example files with git index blob SHAs), `cmake-example-refs.tsv` (1834 CMake references),
  `example-targets.tsv`, `ctest-registrations.tsv` (1756 registrations),
  `example-consumers.tsv` (per-source consumer sets), plus per-variant configured-tree
  captures `ctests-*.txt` / `targets-*.txt` (HEADLESS, OPENGLES3, VULKAN, DIRECTX11-cross).
- `move-map.tsv` — old path → classification → owner → new path for all 1373 files
  (generated by `modularization/tools/example_move_map.py`).
- `after/` — the same inventory captured at the campaign head (1417 files = the 1373 plus
  44 module-local `examples/CMakeLists.txt` build files), plus the per-variant captures.
- `modularization/tools/example_inventory.py` — the capture tool;
  `modularization/tools/reconcile_examples.py` — the no-loss gate.

  renderer-agnostic XNA graphics API validation, instantiated per renderer by the family
  suites (up to 17 families consume a single source).
- `avatar_*_integration_test.cpp` → gamer-services (AvatarRenderer API), instantiated by the
  EasyGL and Vulkan suites.
- `common/` support headers → graphics examples/common, except the two single-family
  helpers (LlglVulkanWsiSkipGuard.cpp → llgl, SkiaSuccessorOracle.hpp → skia).
- **Top-level remainder — `examples/golden/` (17 PNGs), SHARED_EXAMPLE_ASSET**: the

  the documented shared asset location. No other tracked file remains under top-level
  `examples/`.
- No tracked core/math/runtime/content/storage/media/devices-ext-specific examples exist;
  those modules simply have no `examples/` directory (none invented for symmetry).

## No-loss reconciliation (reconcile_examples.py) — PASS

- 1373 baseline files → 1346 moved byte-identical (same git blob) + 10 moved with declared
  edits + 17 kept in place; nothing lost, nothing extra beyond the 44 declared
  module-local build files.
- The 10 required edits, by permitted class:
  - include path (8): the avatar demos' + net_avatar_sync's `../../common/*.hpp` →
    `common/*.hpp` (resolved via `CNA_GRAPHICS_EXAMPLES_DIR`);
  - local CMake ownership (1): the Android subproject's repo-root `add_subdirectory`
    climbs eight levels from its new depth instead of six;
  - asset/resource path (1): `skia_ganesh_resource_budget_test.cpp`'s diagnostic message
    cites its sibling source by repository path.
- CTest registrations: **1756 before == 1756 after, identical name multiset** parsed from
  the CMake sources (`ctest-registrations.tsv` both sides).
- Example target names: `make help` real-target sets are **identical** on all four
  captured variants (HEADLESS/OPENGLES3/VULKAN/DIRECTX11); no target appeared or vanished.
- No example target was renamed (target-rename count: 0).

## Configured-tree ctest capture — derivation note

The baseline `ctests-*.txt` under `baseline/` were captured twice; both raw captures are
imperfect in ways that cancel exactly, and the arithmetic is recorded here deliberately:

1. The first capture's parser missed ctest's right-aligned low test numbers, dropping
   tests #1–#999 in the three big trees (#1–#9 in the DIRECTX11 tree). Its retained-name
   sets are a strict subset of the after sets (verified directly for HEADLESS).
2. The second capture (correct parser, taken by flipping this worktree back to
   `16f76cf1a` and reconfiguring the same build trees) double-counts family tests: the
   reused binary trees retained the module-subdirectory `CTestTestfile` layers from the
   new structure alongside the old root-scope registrations. Its **unique**-name set is
   exact, and equals the after unique-name set (modulo two pre-existing
   gtest value-printer padding bytes in AUD08 audio test names).
3. Totals: first-capture retained + dropped == after totals **exactly** on all four
   variants — 76 (DIRECTX11), 6161 (HEADLESS), 6564 (OPENGLES3), 6462 (VULKAN) — and the
   after captures are duplicate-free. Old-set ⊆ after-set with equal cardinality ⟹ the
   registered test set is identical.
4. Independently, the source-level registration parse (1756 names) is identical
   before/after, covering every family and configuration, not only the four configured
   variants.

## Behavioral regressions found by the gate reruns, and fixed in-campaign

1. **Skip convention**: the root one-shot `SKIP_RETURN_CODE 77` (Task 470) only covers
   root-scope registrations; module-registered tests lost it (two HEADLESS contract tests
   reported Failed instead of Skipped). Fixed by `cna_apply_skip_convention()`
   (cmake/TestHelpers.cmake) called at the end of all 44 module example files.
2. **Test working directory**: ctest's implicit CWD is the registering directory's binary
   dir; root-registered tests historically ran at the top build directory, where the
   executables and their POST_BUILD Content/ live. `Vulkan_Demo2D_SmokeTest` aborted
   deterministically on Content lookup after the move. Fixed by pinning
   `WORKING_DIRECTORY ${CMAKE_BINARY_DIR}` as the default in
   `cna_register_renderer_test()` and explicitly at the eight moved raw `add_test` sites.
3. **Cross-family example reuse**: nine families compile sources owned by sibling
   families (Vulkan/DirectX/OpenGL2/… building EasyGL-authored golden fixtures, EasyGL
   building `vulkan_fill_mode_test.cpp`, DirectX11 building bgfx-authored fog fixtures).
   The first mechanical rewrite pointed all foreign sources at the graphics module; the
   existence-checked second pass re-pointed every such reference at its real owner
   (`${CMAKE_SOURCE_DIR}/modules/renderers/<owner>/examples/...`). All four variant
   configures generate cleanly afterwards.
